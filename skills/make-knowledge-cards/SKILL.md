# 知识卡片生成

把一篇文章拆成若干张卡片，每张卡片只讲一个知识点，供复习和自测使用。

## 适用范围

支持：

- 用户直接粘贴到对话里的文章正文
- 本地 `.md` / `.txt` 文件的路径（用 Read 读取，不要用 shell 拼接输出）

不支持，遇到时直接说明能力边界，不要绕道实现：

- 网页抓取、URL、需要登录的页面
- PDF、图片、扫描件、音视频
- Anki 牌组导入导出、图形界面
- `.docx`、`.xlsx`、`.pptx`

## 生成流程

1. **取全文**：粘贴文本直接用；本地文件先完整读取，长文件分段读完再开始提炼，不要只看开头就出卡。
2. **切知识点**：按"一个可独立记住、可独立复习的结论/定义/方法/步骤"切分。同一主题在不同段落重复出现的，合并成一张卡。
3. **去重与排序**：删掉重复表述、铺垫、过渡句、口号式内容。按原文逻辑顺序排列卡片，先主干后细节。
4. **定数量**：见下节"数量策略"。
5. **写卡片**：按"卡片四要素"逐项填写，最后做"质量自检"。

## 数量策略

| 原文独立知识点数 | 输出 |
| --- | --- |
| 少于 5 个 | 有多少输出多少，并在末尾用一句话说明"原文知识点不足以生成 5 张" |
| 5 到 8 个 | 全部输出，每点一张 |
| 多于 8 个 | 只保留最核心的 8 个，舍弃边角信息，不压缩成合并卡 |

数量服务于信息量，不要为凑数拆分同一个知识点，也不要把两个知识点塞进一张卡。

## 卡片四要素

- **标题**：一个名词短语或短句，说明这张卡讲什么，不超过 15 字。避免"要点一""知识点 2"这类无信息标题。
- **核心知识**：一句话结论，是这张卡最该被记住的东西。可用原文措辞，但不要照抄整段。
- **简明解释**：2 到 3 句，说清"为什么/怎么用/适用条件"。只做原文信息的通俗化，不引入原文没有的原因、机制、数据，也不补充原文没写的注意事项、风险提示、操作前提。
- **例子或自测**：优先用原文自带的例子、案例、数据；原文没有例子时，基于原文概念出一道自测题（问答或判断题），答案必须能从原文推出。不要编造新案例、新数字。

## 输出模板

每张卡片固定如下格式，卡片之间空一行，不加开场白、不加总结段、不加 Markdown 标题：

```text
【知识卡片 1】
标题：<标题>
核心知识：<一句话结论>
简明解释：<2-3 句>
例子/自测：<原文例子，或自测题+参考答案>
```

正文采用用户使用的语言；专有名词保留原文写法。

卡片数少于 5 时，在最后一行补一句 `说明：原文只有 N 个独立知识点，因此输出 N 张，不补足到 5 张。`这句话不编号、不算卡片内容，其他情况不要出现任何附加说明。

## 质量自检

输出前逐条检查，任一不满足就返工：

1. 每张卡是否只有一个知识点，标题能否独立说明它。
2. 是否还有两张卡在讲同一件事，有则合并。
3. 解释和例子里的每条信息，能否在原文找到依据；无依据的删掉，不要"补全"。
4. 卡片数是否与知识点数匹配，没有硬凑、没有漏掉主干。
5. 格式是否完整，四要素齐全，编号连续。
6. 议论文、评论、观点类原文，分论点按"作者主张"表述，不要写成已被验证的客观事实。

## 禁止事项

- 编造原文没有的定义、因果、数据、案例、作者观点。
- 把原文的一段话原样复制当"核心知识"。
- 把原文的次要细节（人名、年份、修饰语）都拆成卡片。
- 在卡片之外添加推荐语、学习建议、延伸阅读等原文没有的内容。
- 给操作步骤补充原文没写的前提条件、风险提示或替代做法。
- 输出成文件、Anki 牌组或图片，除非用户明确要求这些形式。
